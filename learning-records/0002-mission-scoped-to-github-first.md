# Mission scoped to Git & GitHub, with two topics deliberately deferred

The user named three things they wanted to learn — Git/GitHub, authoring Claude
Code skills, and agent/LLM engineering — then resolved the ambiguity themselves:
Git and GitHub first, because it is the substrate the other two are delivered
through, and because a visible GitHub track record is what converts five years of
security study into something an employer in cybersecurity, AI GRC, or AI training
can actually see.

**Implications.** One mission per workspace, so [[MISSION.md]] covers Git and
GitHub only; the other two are recorded there as a deferred arc, not dropped. Do
not drift lessons toward skill-authoring or agent engineering to seem relevant —
when Git and GitHub are automatic, that is the trigger to revisit the mission with
the user, and that revision gets its own learning record.
